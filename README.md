College Placement Analysis Dashboard
=====================================

HOW TO USE
1. Extract this zip.
2. Double-click index.html (or open it in any modern browser — Chrome, Edge, Firefox).
3. No installation, server, or internet connection is required for the dashboard
   itself to run — it only needs internet the first time to load two CDN files
   (Chart.js for charts, Google Fonts for typography). If you're fully offline,
   the page still works, just with fallback system fonts and no charts.

WHAT'S INSIDE
- A single self-contained website (index.html) with everything embedded:
  HTML, CSS and JavaScript in one file.
- A synthetic dataset of 1,500 student records is generated in-browser using a
  fixed random seed, so every time you open the file you get the SAME dataset
  (useful for screenshots / consistent demo runs).
- 6 sections: Overview, Student Performance, Skills & Experience,
  Salary Analysis, Insights & Recommendations, and Dataset.
- 13 interactive charts, 6 KPI cards, 6 live filters (branch, gender,
  placement year, internship, placement status, company type).
- Auto-generated insights and recommendations that recompute from the current
  filter selection — every number shown is calculated, not hardcoded.
- A "Download full dataset (CSV)" button on the Dataset tab lets you export the
  full 1,500-row dataset to use separately in Excel, SQL or Python for the
  other parts of your academic project.

IMPORTANT NOTE
This dataset is SIMULATED / ACADEMIC data generated for a B.Tech project.
It does not represent real placement records of any actual college and should
not be cited as such.
