Simulated / academic data generated for coursework purposes. Relationships between CGPA, attendance, internships, backlogs and placement are intentionally modelled with realistic noise — not perfectly linear — to mirror real-world unpredictability.

College Placement Analysis Dashboard — B.Tech Data Analytics Project. Dataset is synthetically generated in-browser (no external data source) and regenerates identically on reload via a fixed seed. Figures shown are illustrative and must not be cited as real placement statistics of any institution.
